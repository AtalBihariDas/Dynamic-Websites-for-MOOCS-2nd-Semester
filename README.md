

#  Dynamic Web Projects (HTML, CSS, JavaScript)

This repository contains two dynamic front-end web applications built using **HTML, CSS, and JavaScript**. These projects demonstrate client-side interactivity, DOM manipulation, and basic data handling without a backend.

---

## 1. E-Commerce Website

###  Overview

A dynamic e-commerce interface where users can browse products, add them to a cart, and proceed to checkout by entering delivery details.

###  Features

* Display of multiple products with images
* Add to Cart functionality
* Dynamic cart updates (quantity, total price)
* Remove items from cart
* Checkout system with delivery address form
* Order summary/receipt generation

### 🛠️ Technologies Used

* HTML (Structure)
* CSS (Styling & Layout)
* JavaScript (Logic & Interactivity)

###  Functional Flow

1. User browses available products
2. Adds items to cart
3. Views cart summary
4. Enters delivery address
5. Proceeds to checkout and gets order confirmation

---

##  2. Student Management System

###  Overview

A dynamic system to manage student records across multiple streams with search functionality.

###  Features

* Three streams (e.g., Science, Commerce, Arts)
* Add student details:

  * Enrollment ID
  * Name
  * Marks
* Store students stream-wise
* Search student by Enrollment ID
* Display student details dynamically

### 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

###  Functional Flow

1. Select a stream
2. Add student details
3. Store and display student list
4. Search student using Enrollment ID
5. Retrieve and show student information
